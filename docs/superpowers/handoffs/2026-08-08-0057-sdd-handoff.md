  configures `imap_addr` / `smtp_addr`.
- Wizard triggers only when a required field is missing AND stdin is a TTY.
- Non-interactive mode prints a hint and exits 2.
- Auth code is read with `golang.org/x/term.ReadPassword` (new dep) and
  never persisted. Env `AGENT_AUTH_CODE` and `--authcode-file` are the
  only ways to inject it.
- Wizard persists non-secret fields to `~/.config/perch/perch.yaml` with
  `0600` perms.
- Old YAML keys (`imap_addr` / `smtp_addr` / `agent_bin` /
  `claude_workdir` / `claude_permission_mode`) emit a single WARN each,
  then are ignored.
