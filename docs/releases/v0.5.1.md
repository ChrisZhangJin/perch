# perch v0.5.1

A bug-fix release: on 2026-10-10 the duration probe failed at every step of
`Jev → llm → agent probe`, so no task got an acknowledgement.

Upgrading is a drop-in.

## Fixed: the LLM fallback answered with an empty string

`max_tokens` was 16. Reasoning models (deepseek) count their hidden thinking
against that cap, spent all 16 tokens thinking, and returned `content: ""`
— logged as `llm answer unusable … unrecognised answer ""`. The cap is now
16384.

## Changed: LLM timeout default 15s → 2m

With room to reason, a chat model can take well past 15 seconds. The call
still runs inline, so a hung provider stalls the mailbox up to this long. An
explicit `llm.timeout` in `perch.yaml` still overrides the default.

## Fixed: the pi agent probe always failed

The throwaway classify probe runs with an empty session id, and perch passed
`--session-id ""` to pi, which rejects it ("Session id must be non-empty").
The session flag is now omitted when the id is empty.
