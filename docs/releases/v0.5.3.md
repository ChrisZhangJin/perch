# perch v0.5.3

A bug-fix release for the LLM fallback.

Upgrading is a drop-in.

## Fixed: large LLM responses failed to decode

perch read at most 64 KiB of an LLM response and silently dropped the rest.
Reasoning models (deepseek) return their thinking, plus per-token logprobs,
in the body, which passes 64 KiB once `max_tokens` is large. The cut body
failed with `llm: decode response: unexpected end of JSON input`.

The read cap is now 16 MiB. A body over the cap, or a read that fails
mid-way, is now reported as such instead of being decoded half-read.

## Changed: `llm answer unusable` logs the response

The warning now carries `body_bytes` and the start of the body, so an
unexpected answer can be diagnosed from the log alone.

## Note

An explicit `llm.timeout` in `perch.yaml` overrides the 2m default from
v0.5.1. If yours still says `timeout: 15s`, raise it or delete the line.
