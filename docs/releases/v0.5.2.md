# perch v0.5.2

Makes the LLM answer budget configurable and raises its default.

Upgrading is a drop-in.

## Changed: `max_tokens` default 16384 → 131072 (128k)

Reasoning models count their hidden thinking against `max_tokens`; too
small a cap returns an empty answer (`unrecognised answer ""`).

## New: `llm.max_tokens`

```yaml
llm:
  max_tokens: 128k   # plain number or k/m suffix: 131072, 128k, 1024k, 1m
```

`k` is ×1024 and `m` is ×1024×1024. perch sends the value as-is; a provider
whose output cap is lower rejects the call with HTTP 400 — lower it then.
The startup line `"llm fallback enabled"` now logs `max_tokens`.
